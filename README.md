# Mis Inicios en Ingeniería Civil en Ciencia de Datos

¡Hola! Este repositorio es un portafolio personal que recopila los primeros scripts y algoritmos que desarrollé en Python durante mis primeros pasos en la carrera. 

El objetivo de este espacio es documentar mi evolución en los fundamentos de programación en python, la resolución de problemas lógicos y la aplicación de fundamentos matemáticos aplicados a la computación.

El código abarca desde ejercicios básicos de lógica de programación hasta pequeñas herramientas funcionales:

* **Lógica y Algoritmia Básica:** Ejercicios de estructuras de control (`bucle.py`), validaciones y manejo de flujos.
* **Cálculo y Geometría Aplicada:** Algoritmos para resolver problemas matemáticos de forma automática.
* **Simulaciones de Sistemas:** Desafíos prácticos de lógica de negocio y control de datos.

## Tecnologías Utilizadas

* **Lenguaje principal:** Python 3.x
* **Entorno de desarrollo (IDE):** Visual Studio Code
* **Control de versiones y entorno:** Git + Git Bash
* **Alojamiento de código:** GitHub
